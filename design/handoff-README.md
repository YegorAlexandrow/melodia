# Хендофф: Каталог виниловых пластинок «Мелодия»

## Обзор

Персональное (однопользовательское, self-hosted) веб-приложение для каталогизации
домашней коллекции винила с акцентом на фирму «Мелодия». Пользователь вводит
каталожный номер → данные релиза подтягиваются из Discogs → создаётся карточка
**экземпляра** с треклистом, сторонами и обложкой. К экземпляру и отдельным трекам
привязываются свои оцифровки (needledrop), две независимые оценки (музыка / звук),
заметки (markdown) и журнал прослушиваний. Всё личное датировано и не теряется.

Полный исходный бриф — в `brief.md`. Модель данных (MongoDB + Beanie) — в `catalog.py`.

---

## О файлах в этом пакете

Файлы `*.dc.html` — это **дизайн-референсы, созданные в HTML** (прототипы,
показывающие задуманный вид и поведение), **а не продакшен-код для копирования**.
Задача — **воссоздать эти дизайны в среде целевого кодовой базы** (бриф предлагает
Python + FastAPI + MongoDB + Beanie на бэкенде; фронтенд на усмотрение — React/Vue/
любой), используя её устоявшиеся паттерны и библиотеки. Если фронтенд-окружения ещё
нет — выбрать подходящий фреймворк и реализовать дизайны в нём.

Прототипы написаны как «Design Components» (рантайм `support.js`). Чтобы просто
посмотреть их в браузере, откройте `.dc.html` рядом с `support.js`. Логику и стили
читайте как спецификацию, а не как код к переносу 1:1 — стайлинг инлайновый
намеренно (так требует среда прототипа), в продакшене используйте CSS-переменные
(см. раздел «Токены»).

## Уровень проработки (fidelity)

**High-fidelity (hifi).** Финальные цвета, типографика, отступы, состояния и
взаимодействия. Воссоздавайте интерфейс пиксель-в-пиксель средствами вашей кодовой
базы. Точные значения — ниже и в `Дизайн-система — Конверт.dc.html`.

## Визуальное направление

Направление **«Конверт»**: редакционная подача, обложка как объект, крупная
серифная типографика. Вдохновение — советский грамзаписывающий дизайн 1960–80-х
(модернизм, кириллица как графика, плотные сетки, ограниченная палитра, бумага
конвертов). Тёплая, предметная, «архивная» эстетика без глянца.

> Важно: фирменный логотип/стиль «Мелодии» — охраняемый товарный знак. В продукте
> он НЕ используется. Обложки-плейсхолдеры — собственная графика (цветное поле +
> намёк на диск + кант + типографика), её и держим до загрузки реальных сканов.

### Шрифты (Google Fonts)
- **Cormorant Garamond** — дисплей/заголовки (700), артист курсивом (italic 500–600).
- **PT Sans** — основной текст интерфейса (400/700).
- **PT Mono** — каталожные номера, матрицы, даты, технические данные, надзаголовки
  (uppercase, letter-spacing .16–.2em).

### Прочее
- Радиусы: **2px** (по умолчанию), **3px** (крупные карточки/модалки), **50%** (аватары, кнопка ▶).
- Шкала отступов: 4 · 8 · 14 · 22 · 30 · 48.
- Тип-шкала: дисплей 44–48 / секции 21–24 / body 14–15 (1.5) / mono 11–14 / надзаголовок 10–11 uppercase.
- Переходы темы: `background/color .35s ease`. Подсветка по наведению строк: `background: var(--raise)`.

## Экраны

### A. Коллекция (главный экран)
- **Назначение:** просмотр/поиск собрания; точка входа в карточку и в «Добавить».
- **Раскладка:** контейнер `max-width:1280px; margin:0 auto; padding:34px 30px 70px`.
  Шапка: слева надзаголовок (PT Mono, --red) + h1 «Коллекция» (Cormorant 700, 46px);
  справа поле поиска (подчёркнутый инпут) + переключатель **сетка/список**
  (тёмный сегмент-контрол). Ниже — ряд чипов-фильтров (жанры) с разделителем `--line`,
  справа счётчик «N из M · по году ↓».
- **Сетка (grid):** `grid-template-columns:repeat(4,1fr); gap:28px 26px`. Карточка =
  обложка-плейсхолдер (`aspect-ratio:1`, `box-shadow:var(--shadow)`) + под ней:
  название (Cormorant 600, 20px) и год (PT Mono, --faint) в одной строке; артист
  (--muted, 13px); строка статуса = бейдж + оценка `муз·звук` (PT Mono, --gold) +
  индикаторы `♪ ✎` (--faint). Вся карточка кликабельна → экран C.
- **Список (list):** таблица в рамке `--line`, шапка-строка PT Mono uppercase.
  Колонки: `44px 1.6fr 130px 110px 90px 130px` = миниатюра обложки · Артист·Название ·
  Каталог № · Завод · Оценки · Статус. Строки `border-bottom:var(--hair)`, hover
  `--raise`, клик → экран C.
- **Пустое состояние:** ведёт к сценарию «Добавить пластинку» (паттерн пустого
  состояния — см. ДС: dashed-рамка `--line`, иконка, курсивная подпись Cormorant).

### B. Добавление пластинки
- **Назначение:** найти издание в Discogs и создать экземпляр.
- **Раскладка:** `max-width:1080px`. Ссылка «← коллекция» (PT Mono, --muted). h1
  «Добавить пластинку». Поясняющий абзац. Строка ввода: инпут кат.№ (рамка `1.5px
  solid --ink`, PT Mono, лейбл «КАТ. №», маркер-каретка `--gold`) + кнопка «Искать»
  (`--blue`). Под ним PT Mono-хинт: `нормализовано: <catalog_number_norm>` и ссылка
  «найти по артисту + названию».
- **Результаты Discogs:** заголовок «Результаты Discogs» + рамка-линия + счётчик
  «N совпадений · лимит 58/60» (показываем остаток rate-limit). Сетка карточек
  `1fr 1fr; gap:14px`. Карточка-кандидат: миниатюра 82px + метка совпадения
  (точное=green / версия=gold / похоже=`#a89c80`) + кат.№ + название (Cormorant 600)
  + артист + мета `год · страна · формат`. Рамка `--line`; при выборе — `--red` +
  «выбрано ✓».
- **Подтверждение:** после выбора снизу разворачивается панель «Будет создан
  экземпляр»: слева предпросмотр треклиста по сторонам, справа подтянутые данные
  (артист, год·страна, формат, матрица, «Обложка: кэшируется локально ✓»),
  чекбокс «У меня несколько прессов этого издания», кнопки «Создать карточку»
  (`--red`) / «Отмена».

### C. Карточка экземпляра — главный экран
- **Назначение:** рабочее место пользователя; всё про конкретный физический диск.
- **Раскладка:** `max-width:1180px`. Строка над карточкой: «← коллекция» + переключатель
  **десктоп / смартфон**. Сама карточка — `box-shadow:var(--shadow)`, рамка `--line`
  (десктоп) или `8px solid #1c1a17` + `border-radius:34px` (смартфон-рамка).
- **Шапка (header band):** flex, на десктопе горизонтально, на мобиле колонкой.
  Слева большая обложка (320px / на весь верх в мобиле). Справа на `--raise`:
  строка статуса-бейдж + «экземпляр №1 из 2» + ★ избранное (toggle, --gold/--faint);
  артист курсивом (--red); название (Cormorant 700, 44px); ряд мета-пилюль
  (год · Мелодия · режим · жанр, рамка `--line`); две оценки крупными цифрами
  «Музыка» (--gold) и «Звук пресса» (--blue), формат `N/5`.
- **Тело:** grid `1.5fr 1fr` (десктоп) / `1fr` (мобиле), gap 30.
  **Левая колонка:**
  - *Треклист* (аккордеон) — по сторонам A/B…: строка трека = позиция (PT Mono,
    28px колонка) · название (Cormorant 19px) · иконки `♪ ✎` (--gold) · длительность
    (PT Mono). Клик по строке разворачивает деталь трека + кнопки «+ аудио к треку»,
    «+ заметка».
  - *Аудио* (аккордеон) — кнопка «+ добавить» → экран E. Строка = круглая ▶
    (needledrop=--red / reference=--gold) + название + мета (PT Mono) + метка
    роли. Пустое состояние курсивом.
  - *История оценок* (аккордеон, по умолчанию свёрнута) — строки: дата (--red) ·
    «муз N» (--gold) · «звук N» (--blue) · заметка курсивом.
  **Правая колонка** (все аккордеоны):
  - *Пресс и сохранность* — пары ключ/значение через `1px dotted --line`: завод,
    матрица (PT Mono), режим·скорость, ГОСТ, год пресса. Ниже два грейд-блока
    на `--field`: пластинка (--green) и конверт (--gold).
  - *Покупка и стоимость* — где, когда, цена покупки, оценка Discogs (--green), полка.
  - *Заметки* — лента: `border-left:3px` (закреплённые --gold, прочие --blue),
    заголовок + дата + «★ закреплено», тело.
  - *Журнал прослушиваний* (свёрнут по умолчанию) — дата (--red) · что слушал ·
    на чём; внизу сводка.

### D. Лента заметок (сквозная)
- **Назначение:** все заметки коллекции по дате; «когда и что я писал».
- **Раскладка:** `max-width:860px`. Надзаголовок + h1 «Заметки». Чипы-фильтры
  (Все / Закреплённые / по жанрам). Строки: миниатюра обложки 58px + заголовок
  (Cormorant) + ★ + дата (справа, PT Mono) + ссылка-референс «Артист — Название»
  (PT Mono uppercase, --red) + тело. Клик → карточка этого экземпляра. Закреплённые
  поднимаются вверх.

### E. Аудио: добавление/редактирование
- **Назначение:** привязать оцифровку/референс к треку/стороне/диску.
- **Раскладка:** `max-width:880px`. «← <название>» + h1 «Привязать аудио».
  Grid `1fr 1fr`. Левая: дроп-зона (dashed `--line`) для файла; радио-группа
  «Привязка» (К треку / К стороне / Ко всему диску / Внешний референс) — активная
  опция рамка+точка `--blue`; при «к треку» — селектор трека. Правая: авто-тех-поля
  (формат, частота, разрядность, каналы) в мини-карточках + «Обстоятельства
  оцифровки» (головка, фонокорректор, АЦП, обработка). Кнопки «Сохранить» (--blue) /
  «Отмена».

### F. Дашборд / статистика
- **Раскладка:** `max-width:1080px`. Надзаголовок + h1 «Статистика». Ряд из 4
  стат-карточек (`repeat(4,1fr)`): всего / в коллекции (--green) / с оцифровкой
  (--blue) / в розыске (--red) — крупная цифра Cormorant + подпись. Ниже две
  колонки: «По заводам» (бары --blue) и «По жанрам» (бары --gold), плюс «Давно не
  слушал» (кликабельные строки → карточка). Бары: трек `--field`, заливка по
  `count/max * 100%`.

## Взаимодействия и поведение

- **Навигация:** верхняя липкая панель (h:62px, `--card`, `border-bottom:--line`):
  вордмарк «Фонотека» (Cormorant) + nav (Коллекция / Заметки / Статистика) +
  кнопка «+ Добавить пластинку» (--red) + переключатель темы (☾/☀). Активный
  пункт nav: текст --ink, фон --raise. На экране карточки активна «Коллекция».
- **Переключатели:** сетка↔список (Коллекция), десктоп↔смартфон (Карточка),
  светлая↔тёмная (глобально, через класс на корне), grid↔list.
- **Аккордеоны:** клик по заголовку секции карточки сворачивает/разворачивает тело;
  индикатор ▾ (открыт) / ▸ (свёрнут). По умолчанию свёрнуты: «История оценок»,
  «Журнал прослушиваний».
- **Трек:** клик по строке разворачивает деталь (один трек открыт за раз).
- **Избранное:** ★ toggle в шапке карточки.
- **Discogs-выбор:** клик по кандидату подсвечивает его и раскрывает панель
  подтверждения; «Создать» → возврат в коллекцию; «Отмена» → сброс выбора.
- **Анимации:** мягкие переходы темы (.35s ease). Без bounce/glanc-эффектов.
- **Hover:** строки списка/ленты — фон `--raise`. Кнопки — затемнение/осветление по
  паттерну кодовой базы.

### Состояния, которые нужно добавить при реализации (в прототипе их нет)
- Загрузка (скелет/спиннер) при запросе к Discogs и при скачивании обложек.
- Ошибки: сеть, 429 от Discogs (показать backoff/повтор), пустой результат поиска.
- Валидация формы аудио и нормализация кат.№ на вводе.
- Пустые состояния всех списков (паттерн есть в ДС).
- Доступность: фокус-кольца, навигация с клавиатуры, ARIA для аккордеонов/радио.
- Адаптив: проработан только экран C (десктоп/смартфон); остальное — десктоп-first.

## Состояние (state)

Из прототипа (ориентир для фронтенд-стейта):
```
screen      'collection' | 'add' | 'card' | 'notes' | 'audio' | 'stats'
view        'grid' | 'list'              // режим коллекции
theme       '' | 'theme-dark'            // класс на корне
device      'desktop' | 'mobile'         // вид карточки
sel         index выбранного экземпляра
filter      жанр-фильтр коллекции
openTrack   позиция раскрытого трека ('A2') | null
cand        индекс выбранного кандидата Discogs | null
binding     'track' | 'side' | 'album' | 'ref'   // привязка аудио
noteFilter  'all' | 'pinned' | <жанр>
sections    { tracks, audio, ratings, press, acq, notes, plays }: bool  // аккордеоны
fav         { [index]: bool }            // избранное
```
Серверная логика (НЕ на клиенте, см. бриф): нормализация кат.№ в
`catalog_number_norm`; инкремент `play_count`/`last_played_at` при создании
`PlayEvent`; скачивание и перекладывание обложек `loc=WEB → LOCAL/S3`;
автозаполнение тех-полей аудио (mutagen). Канон Discogs кэшируется отдельным слоем
(`Master`/`Release` + `raw` + `fetched_at`), личные данные — отдельные коллекции.

## Данные

Реальные доменные особенности (нельзя «спрямлять») — из брифа и `catalog.py`:
- **Экземпляр ≠ издание.** Карточка = физический экземпляр; их может быть несколько
  на одно издание Discogs.
- **Стороны и позиции.** Треки сгруппированы по сторонам A/B/C/D, позиция «A1».
- **Две оценки.** Музыка и звук пресса — раздельно, с историей и датами.
- **Сохранность Goldmine** — раздельно пластинка и конверт (M, NM, VG+, VG, G+, G, F, P).
- **Заводы «Мелодии»** — справочник (Апрелевка/ALZ, ЛЗГ, Рига, Ташкент, Тбилиси,
  Баку, МОЗ, ВСГ) — фильтр и атрибут пресса.
- **Матрица из выплавки** — текст, вписывается вручную; ключевой признак пресса.
- **Статусы:** owned / wanted / ordered / sold / gifted / lent_out.
- **Всё датировано.**

## Ассеты

- Обложки: в прототипе — **собственные плейсхолдеры** (CSS, без изображений).
  Реальные сканы пользователь приложит; в БД хранится только локатор (`ImageMedia`:
  key + loc + mime_type), публичный URL собирается на отдаче, обложки кэшируются
  локально/в S3.
- Иконки: Unicode-глифы (⌕ ▦ ≣ ▶ ★ ☆ ☾ ☀ ▾ ▸ ♪ ✎ +). При реализации можно заменить
  на иконочный набор кодовой базы (тонкий штрих, в духе печатной эстетики).
- Логотип «Мелодии» НЕ используется (товарный знак). Вордмарк продукта — «Фонотека»
  (Cormorant Garamond 700).
